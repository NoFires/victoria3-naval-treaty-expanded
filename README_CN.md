**加载顺序：**建议置于基础框架类 Mod（如 Community Mod Framework）之后、大型全面修改 Mod 之前。本模组在任意加载顺序下均与 **[铁与蒸汽：海军大修（Iron & Steam: Naval Overhaul）](https://steamcommunity.com/sharedfiles/filedetails/?id=3726415174)** 完全兼容。

## 当前版本内容（`v0.2.0 Demo`）

### 真实吨位与海军学说核算引擎
- 不再以简单舰船数量衡量海军规模，而是依据舰船时代、海军力量投射与船体耐久（HP）计算单舰真实条约吨位。
- 主力舰（风帆战列舰至超级无畏舰）与巡洋舰（护卫舰至航空母舰）计入条约限额；驱逐舰与潜艇不计入条约吨位限制。
- 与海军学说深度联动：**新锐学派**享有巡洋舰吨位 `0.72` 倍核算减免，**外交海军**提供 `+15%` 条约议会投票权重加成。

### 全球海军限武条约（锁定阶梯配额）
- 解锁国际关系相关科技后，列强与主要政权可通过外交条约共同缔结全球海军限武条约，并激活共享日志条目。
- 依据签约时海军实力分配 **`5 : 5 : 3 : 1.75 : 1.75 : 1.35`** 阶梯配额并锁定前两席位阶，防止后续新成员加入挤占既定席位。
- 内置透明化多维 AI 接受度系统（舰队战力比、含黄金储备缓冲的军费财政压力、海军学说、外交战略、外交互信等），全面适配 `1.15` 原生日志地图着色、状态悬停提示以及**条约全球稳定度**、**本国配额占用率**双进度条。
- 所有全局核算、配额分配、修订表决与主席国顺位交接均由唯一主席国统一结算，确保多人联机状态完全同步。

### 日志外交博弈与条约履约机制
- **加权修订与制裁投票**：成员国可基于真实舰队规模与外交权重发起 `-15%` 至 `+15%` 连续上限修订，或以 `75%` 权重投票对违约国实施外交孤立制裁。
- **自动扶梯条款**：当条约外主要海军强国膨胀至威胁第二位阶配额的 `80%` 以上时，成员国可援引自动扶梯条款临时上调 `20%` 上限并加速主力舰建造。
- **海军假日、封存与拆解**：支持发起三年期“海军假日”、和平时期封存后备舰队（`-18%` 核算吨位与 `-20%` 维护费，代价为投射与主力舰建造效率下降）及老旧战舰拆解转产计划。
- **潜艇议定书与秘密虚报**：可消耗外交影响力签署《伦敦潜艇议定书》约束破交与提升声誉，亦可冒险“虚报吨位”隐瞒 `12%` 账面吨位，但一旦在情报互换或质检中败露将面临严厉制裁。

### 双边海军限武条约（强权约束与战争强迫）
- 具有强迫性与屈辱性的单边裁军协议：默认将受约国舰队吨位限制为主导方的 **`60%`**，条约生效后主导方可通过外交照会事件在 **`30% / 50% / 60% / 75%`** 之间选择约束档位（不同严苛度对应不同外交成本与关系变化）。
- 支持作为**外交博弈战争目标（Wargoal）**在战争中强制城下之盟签订。
- 受限国超标后将进入 3 个月宽限期并承受主力舰建造减速；若双方关系恶劣且拒不退让，将触发三阶段最后通牒与惩罚性外交博弈事件链。

### 与《铁与蒸汽：海军大修》的联动协同
- 专为与 **[铁与蒸汽：海军大修](https://steamcommunity.com/sharedfiles/filedetails/?id=3726415174)** 搭配游玩而设计。
- 双模组同时启用时，自动检测并动态抬升超级主力舰质检阈值，接入新舰竣工联动通知，并在主菜单展示联合兼容徽章。
- 由于本模组根据船体耐久（HP）与海军力量投射计算真实吨位，**Iron & Steam: Naval Overhaul** 中的 10 槽位高阶舰船改装将直接转化为“单舰质量与舰队总吨位”的真实战略取舍。
- 不受条约限制的护航驱逐舰与潜艇（搭配通气管、水听器与新锐学派）将成为受限强国与中小海权国家打破封锁的关键非对称手段。
